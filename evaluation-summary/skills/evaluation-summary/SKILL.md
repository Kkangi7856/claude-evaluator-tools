# Evaluation Summary — 평가의견 항목별 종합 정리

## 개요

여러 평가위원의 답변이 담긴 엑셀을 받아, **항목별로 의견을 중복 없이 정리**한 한글 문서를 생성한다.

- 입력 엑셀 기본 구성: **A열 = 평가위원명**, **C열 = 우수한 점**, **D열 = 수정 및 보완할 점**, **E열 = 기타 의견**
- 3개 항목에 대해 여러 평가위원의 의견이 **서로 겹칠 수 있다.**
- 출력: `1. 우수한 점`, `2. 수정 및 보완할 점`, `3. 기타 의견` 아래에 겹치지 않는 의견을
  `ㅇ ~~` 형식으로 정리한 한글(.hwp).
- **평가위원 이름은 출력에 넣지 않는다.**

## 작업 절차

### 1단계 — 원문 추출
엑셀에서 평가위원별 원문 의견을 JSON 으로 추출한다.
```
python "${CLAUDE_PLUGIN_ROOT}/skills/evaluation-summary/scripts/render_summary.py" --extract "평가표 답변 목록.xlsx"
```
- 출력: `[{ "name": ..., "우수한 점": ..., "수정 및 보완할 점": ..., "기타 의견": ... }, ...]`
- 열 위치가 다르면 옵션으로 지정: `--name-col A --good-col C --fix-col D --etc-col E`
  (헤더가 있으면 `--header-row 1`, 데이터 시작 행 `--start-row 2` 가 기본값).

### 2단계 — 항목별 중복 제거·정리 (Claude 가 수행)
세 항목 **각각**에 대해 다음을 수행한다.
1. 모든 평가위원의 해당 항목 텍스트를 모은다.
2. **의미가 겹치는 의견은 하나로 병합**한다(동일·유사 논점 중복 금지).
3. 서로 다른 논점을 각각 하나의 항목으로 만들고, 문장을 자연스럽게 다듬는다.
   - data(원문)의 취지와 근거는 유지하되 문맥·표현은 바꿔도 된다.
   - **평가위원 이름·번호는 넣지 않는다.**
   - 문두의 `ㅇ ` 접두는 렌더링 시 자동으로 붙으므로 텍스트에는 넣지 않아도 된다(넣으면 중복 방지 처리됨).
4. 의견이 하나도 없는 항목은 빈 배열로 둔다(없는 내용을 지어내지 않는다).

### 3단계 — 스펙(JSON) 작성
아래 스키마로 `summary_spec.json` 을 작성한다.

```json
{
  "title": "평가의견 종합",
  "sections": [
    { "heading": "1. 우수한 점",          "items": ["...", "..."] },
    { "heading": "2. 수정 및 보완할 점",   "items": ["...", "..."] },
    { "heading": "3. 기타 의견",          "items": ["..."] }
  ]
}
```

| 키 | 설명 |
|---|---|
| `title` | 문서 제목(생략 시 "평가의견 종합") |
| `sections` | 항목 배열. 순서대로 렌더링 |
| `sections[].heading` | 항목 제목(예: "1. 우수한 점") — 굵게 |
| `sections[].items` | 해당 항목의 정리 의견 배열. 각 원소가 `ㅇ` 한 줄이 됨 |
| `out_name` | 출력 파일명(생략 시 `<title>.hwp`) |

예시는 `references/sample-spec.json` 참조.

### 4단계 — 문서 생성 스크립트 실행
```
python "${CLAUDE_PLUGIN_ROOT}/skills/evaluation-summary/scripts/render_summary.py" --spec "summary_spec.json" --outdir "."
```
- Windows PowerShell 에서는 한 줄로 실행한다.
- 결과: `<title>.hwp` (+ 확인용 `.pdf`).

### 5단계 — 결과 보고
생성된 파일 경로와 항목별 정리 개수(예: 우수한 점 5건 / 보완점 5건 / 기타 2건)를 요약한다.

## 의존성
- **한컴오피스(HWP)** 설치 — 네이티브 `.hwp` 생성에 필요(COM 자동화 `HWPFrame.HwpObject`).
- Python 패키지: `pyhwpx`, `openpyxl` (`pip install pyhwpx openpyxl`).

## 구현 메모(중요)
- 중복 제거는 **Claude 가 의미 기준으로** 수행한다(스크립트는 단순 문자열 정리만 담당).
- 각 `items` 원소는 `ㅇ ` 로 시작하는 한 문단이 되며, 이미 `ㅇ`/`○`/`-`/`1)` 등으로 시작하면
  스크립트가 접두 기호를 정규화한다(이름·번호 중복 방지).
- 항목(heading)은 굵게, 본문은 `ㅇ` 매달림 들여쓰기로 렌더링한다.
- 실행 전 열려 있는 한글 프로세스가 충돌하면 종료 후 재시도한다.
