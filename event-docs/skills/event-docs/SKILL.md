# Event Docs — 행사 개최 계획(안) + 공문 자동 작성

## 개요

행사 개요를 받아 두 개의 한글 문서를 생성한다.

1. **「행사 개최 계획(안)」** — 공공기관 표준 양식(개요·목적·프로그램·일정·소요예산(빈 양식)·기대효과·행정사항)
2. **「공문」** — `assets/gongmun_template.hwp`(워크숍 공문) 서식과 동일한 2종 구성
   - (1면) **개최 계획(안) 보고** — 내부 보고 공문 + 소요예산 빈 표
   - (2면) **참석 요청** — 외부 발송 공문 + 참석자 명단 빈 표 + 붙임

## 입력 (둘 중 하나)
- **웹주소(URL)** — 행사 안내 페이지 (예: 학회/기관 행사 홈페이지)
- **파일** — 행사 개요가 담긴 문서(hwp/pdf/docx/xlsx/txt/이미지 등)

## 작업 절차

### 1단계 — 행사 정보 수집
- URL이면 `WebFetch`로, 파일이면 해당 파일을 읽어 행사 정보를 최대한 추출한다.
- 추출 항목: 행사명, 일시, 장소, 주최/주관, 참가대상, 규모, 개최 목적, 주요 프로그램,
  세부 일정, 문의처 등.
- **정보가 비어 있으면 임의로 지어내지 말 것.** 핵심 항목(행사명/일시/장소)이 없으면
  사용자에게 물어본다. 부가 항목은 비워두거나 합리적 일반 문구를 사용한다.

### 2단계 — 스펙(JSON) 작성
아래 스키마로 `event_spec.json`을 작성한다(스크래치패드 또는 작업 폴더).

| 키 | 설명 | 사용처 |
|---|---|---|
| `event_name` | 행사 정식 명칭 | 제목·본문 전체 |
| `datetime` | 일시 (예: "2026. 4. 28.(화) ~ 4. 30.(목)") | 계획안 개요 |
| `venue` | 장소 | 계획안 개요 |
| `datetime_venue` | "일시 / 장소" 한 줄 (공문용) | 공문 |
| `host` | 주최/주관 | 계획안 개요 |
| `target` | 참가/참석 대상 | 계획안·공문 |
| `report_attendees` | 보고 공문 '참석자' 문구(없으면 target 사용) | 공문(보고) |
| `scale` | 규모 | 계획안 개요 |
| `purpose` | 개최 목적 (문자열 또는 문자열 배열) | 계획안·공문 |
| `programs` | 주요 프로그램 (배열) | 계획안 |
| `schedule` | 세부 일정 (배열: `{division, date, content}`) | 계획안 일정표 |
| `budget_rows` | 예산 항목명 배열(빈 양식용, 생략 시 기본값) | 계획안·(공문 표는 서식 고정) |
| `budget_total` | 소요예산 총액(없으면 "붙임 참조") | 공문(보고) |
| `effects` | 기대효과 (배열) | 계획안 |
| `admin` | 행정사항 (배열) | 계획안 |
| `contact` | 문의처 | 계획안 |
| `gongmun_note` | 참석요청 공문 '기타사항' 문구 | 공문(요청) |
| `attendees` | 초청자 명단 (배열: `{name, org, title}`) — **선택** | 공문(요청) 참석자표 |

예시는 `references/sample-spec.json` 참조.

### 참석자 명단표 자동 채우기 (선택)
`attendees` 배열을 넣으면 참석 요청 공문의 **참석자 명단표(순번·성명·소속·직위)** 가
자동으로 채워진다. 순번은 자동 부여되며, 기본 15행을 초과하면 표에 행이 자동 추가된다.
`attendees` 를 생략하면 표는 **빈 양식(15행)** 으로 남아 수동 기입할 수 있다.

```json
"attendees": [
  {"name": "홍길동", "org": "OO대학교", "title": "교수"},
  {"name": "김철수", "org": "OO연구원", "title": "책임연구원"}
]
```

### 3단계 — 문서 생성 스크립트 실행
```
python "${CLAUDE_PLUGIN_ROOT}/skills/event-docs/scripts/render_docs.py" \
  --spec "event_spec.json" \
  --template "${CLAUDE_PLUGIN_ROOT}/skills/event-docs/assets/gongmun_template.hwp" \
  --outdir "."
```
- Windows PowerShell에서는 한 줄로 실행한다.
- 결과: `<행사명> 개최 계획(안).hwp`, `<행사명> 공문.hwp` (+ 확인용 `.pdf` 각 1부).

### 4단계 — 결과 보고
생성된 두 파일 경로와 주요 내용(행사명·일시·장소·구성)을 사용자에게 요약한다.

## 의존성
- **한컴오피스(HWP)** 설치 — 네이티브 `.hwp` 생성에 필요(COM 자동화 `HWPFrame.HwpObject`).
- Python 패키지: `pyhwpx`, `pandas`, `openpyxl` (`pip install pyhwpx pandas openpyxl`).

## 구현 메모(중요)
- 공문 본문의 가변 텍스트는 `find_replace_all(..., SeveralWords=0)` 로 정밀 치환한다
  (`SeveralWords=1` 기본값은 단어 분할로 **중복 치환·숫자 손실**을 유발하므로 반드시 0).
- 제목은 서식의 누름틀 필드 `결재제목`·`결재제목_2` 에 `put_field_text` 로 채운다.
- 예산표/참석자표는 표 셀을 직접 비워 '빈 양식'으로 만든다(구분·순번·헤더는 유지).
- 계획안의 표는 본문 텍스트를 먼저 쓰고 마커(@@...@@) 자리에 나중에 삽입한다
  (표 생성 후 캐럿이 셀 안에 남아 이후 내용이 표로 들어가는 문제 회피).
- 실행 전 열려 있는 한글 프로세스가 충돌하면 종료 후 재시도한다.
