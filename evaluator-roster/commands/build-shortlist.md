# 최종평가위원 섭외우선(안) 작성

`committee-shortlist` 스킬을 사용해 두 개의 명단 엑셀을 하나로 병합한다.

## 실행 절차

1. **입력 파일 확인** — 인자로 경로가 주어지지 않았으면 현재 폴더에서 다음 기본 파일을 찾는다.
   - 선정: `선정평가위원 및 후보자 명단.xlsx`
   - 단계: `단계평가위원 및 후보자 명단.xlsx`
   - 서식(템플릿): `최종평가위원 섭외우선(안).xlsx`
   파일이 없으면 사용자에게 경로를 물어본다.

2. **의존성 확인** — `openpyxl`이 없으면 `pip install openpyxl`로 설치한다.

3. **스크립트 실행** — 스킬에 포함된 스크립트를 호출한다.
   ```
   python "${CLAUDE_PLUGIN_ROOT}/skills/committee-shortlist/scripts/build_shortlist.py" \
     --seon "선정평가위원 및 후보자 명단.xlsx" \
     --dan  "단계평가위원 및 후보자 명단.xlsx" \
     --template "최종평가위원 섭외우선(안).xlsx" \
     --out "최종평가위원 섭외우선(안)_결과.xlsx"
   ```
   Windows PowerShell에서는 줄바꿈(`\`) 대신 한 줄로 실행하거나 백틱(`` ` ``)을 사용한다.

4. **결과 요약 보고** — 총 인원수와 이력 구분(선정평가위원 / 단계평가위원 / 후보자 등)별 인원을
   사용자에게 표로 요약하고, 결과 파일 경로를 알려준다.

## 판정 규칙 요약
- W열(참석여부) `Y` → 실제 참여 **위원**, 공란 → **후보자**
- K열(국가연구자번호)이 고유키 — 같은 사람이 두 파일에 있으면 **1행**으로 합치고 B열 이력만 결합
- 상세 규칙과 정렬 순서는 `committee-shortlist` 스킬의 `SKILL.md` 참고
