# Committee Shortlist — 최종평가위원 섭외우선(안) 자동 작성

## 개요

두 개의 명단 엑셀을 하나의 섭외우선(안)으로 병합한다.

- **입력 1** `선정평가위원 및 후보자 명단.xlsx`
- **입력 2** `단계평가위원 및 후보자 명단.xlsx`
- **서식** `최종평가위원 섭외우선(안).xlsx` (헤더/테두리 유지용 템플릿)
- **출력** `최종평가위원 섭외우선(안)_결과.xlsx`

## 데이터 구조

### 소스 파일 (두 파일 동일 레이아웃)
- 1행: 제목, 2행: 헤더, 3행~: 데이터
- 주요 열: **J** 성명 · **K** 국가연구자번호(고유키) · **L** 소속기관 · **M** 부서 ·
  **N** 직위 · **R** 전공 · **S/T/U** 기술분류1/2/3 · **W** 참석여부

### 대상 파일 (`최종평가위원 섭외우선(안)`)
- 6행: 헤더, 7행~: 데이터
- **A** 구분 · **B** 기평가 섭외이력 · **C** 후보자성명 · **D** 소속기관 · **E** 부서 ·
  **F** 직위 · **G** 국가연구자번호 · **H** 전공 · **I/J/K** 기술분류1/2/3

### 열 매핑 (소스 → 대상)
| 대상 | 내용 | 소스 |
|---|---|---|
| C | 후보자성명 | J |
| D | 소속기관 | L |
| E | 부서 | M |
| F | 직위 | N |
| G | 국가연구자번호 | K |
| H | 전공 | R |
| I | 기술분류1 | S |
| J | 기술분류2 | T |
| K | 기술분류3 | U |

B열(기평가 섭외이력)만 로직으로 산출하며, A열(구분)은 패널명으로 병합한다.

## 핵심 판정 로직

1. **위원/후보자 판정** — 각 파일에서 **W열(참석여부)** 이 `Y` 이면 실제 참여 **위원**,
   공란이면 **후보자**. (한 파일 내 같은 번호가 여러 행이면 하나라도 `Y`면 위원)
2. **고유키 병합** — **K열 국가연구자번호**로 사람을 식별. 같은 번호가 두 파일에 있으면
   **1행**으로 합치고 B열 이력만 결합한다.
3. **B열(기평가 섭외이력) 산출**

   | 선정 파일 | 단계 파일 | B열 표기 |
   |---|---|---|
   | 위원 | 없음 | 선정평가위원 |
   | 없음 | 위원 | 단계평가위원 |
   | 후보자 | 없음 | 선정평가위원 후보자 |
   | 없음 | 후보자 | 단계평가위원 후보자 |
   | 후보자 | 후보자 | 선정/단계평가위원 후보자 |
   | 위원 | 위원 | 선정/단계평가위원 |
   | 위원 | 후보자 | 선정평가위원 *(위원 우선)* |
   | 후보자 | 위원 | 단계평가위원 *(위원 우선)* |

   > 혼합 케이스(한쪽 위원 + 다른쪽 후보자)는 **위원 이력만** 표기한다.

4. **C~K 데이터 선택** — 두 파일에 모두 있으면 위원 행 → 선정 파일 → 단계 파일 순으로 우선 채택.

## 정렬(섭외우선) 순서
위원 → 후보자 순, 같은 그룹 내에선 원본 등장 순서 유지.

`선정/단계평가위원` → `선정평가위원` → `단계평가위원` →
`선정/단계평가위원 후보자` → `선정평가위원 후보자` → `단계평가위원 후보자`

## 실행 방법

```bash
python "${CLAUDE_PLUGIN_ROOT}/skills/committee-shortlist/scripts/build_shortlist.py" \
  --seon "선정평가위원 및 후보자 명단.xlsx" \
  --dan  "단계평가위원 및 후보자 명단.xlsx" \
  --template "최종평가위원 섭외우선(안).xlsx" \
  --out "최종평가위원 섭외우선(안)_결과.xlsx"
```

인자를 생략하면 위 기본 파일명을 현재 폴더에서 찾는다. `--panel "(패널) OO평가"` 로
A열 구분 값을 지정할 수 있으며, 미지정 시 템플릿의 기존 A7 값을 유지한다.

**의존성:** `openpyxl` (`pip install openpyxl`)

## 주의
- 결과는 원본 템플릿을 덮어쓰지 않고 별도 `_결과.xlsx` 로 저장한다.
- 국가연구자번호가 비어 있는 행은 성명+행번호로 임시 식별(중복 병합 대상에서 제외)한다.
- 스크립트는 값(계산 결과)만 읽으므로, 소스에 수식이 있으면 엑셀에서 한 번 열어 값이
  저장된 상태여야 정확하다.
